## The line

## How it works

`main.ts` writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`),
checks it against the gate (1–200 characters, single line, not only whitespace),
and verifies the written file with a sha256 self-check.

```sh
node main.ts
```
